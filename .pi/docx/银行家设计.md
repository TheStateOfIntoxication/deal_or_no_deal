# 银行家系统设计（v1.0 · 已实现于 v1.4）

**定位**：把《一掷千金》从“算概率的小游戏”变成“**玩家与一个奸猾资本家对赌**”的戏。
**规则权威**：`.pi/docx/需求文档.md`（v1.4）。本设计中的数值修正一律不得破坏 §6.3 边界、R-11.2 提前结算与 R-5.2.7。
**状态**：已按推荐实现（v1.4）：怒气压价 ≤6%（B）、恐惧加价 ≤8%（B）、常驻银行家卡（B）、台词更刻薄（A+）。

---

## 1. 一句话定位

> 银行家不是在“给价”，他是在**买你手里那张可能中大奖的彩票**：你越可能中，他越肉疼；你越穷途末路，他越刻薄。拒绝他，他会记仇。

## 2. 现状回顾

当前报价（需求文档 R-6.1.5）：

```
报价 = 剩余最小值 + (参考锚点 − 剩余最小值) × 乘数(轮次)
乘数 = 0.15 / 0.21 / 0.28 / 0.37 / 0.48 / 0.60 / 0.72 / 0.83 / 0.92
```

问题：乘数只跟轮次有关，**与“玩家中顶奖的概率”无关**，银行家因此没有性格可言，也无法体现“他在赌你拿不到大奖”。

## 3. 人设：万恶的资本家

| 维度 | 设计 |
| :--- | :--- |
| 外形 | 纯 CSS/SVG 卡通剪影：高礼帽、单片眼镜、卷曲八字胡、领结、夹着雪茄的手；不模仿真人、不使用真人素材 |
| 表情 | 4 档：`smug` 眯眼冷笑 → `annoyed` 皱眉 → `angry` 红脸冒气 → `furious` 单片镜碎裂、背景火光 |
| 语气 | 夸张的旧派资本家腔：优雅、刻薄、爱钱、输不起；**不人身攻击、不涉及真实群体**，PG 级 |
| 动作 | 电话铃声（随怒气变调）、敲桌、摔电话、掀桌（怒气满时一次性） |
| 存在感 | 常驻台面右上角（桌面）/ 状态栏下方（移动），报价时放大并说话 |

## 4. 核心博弈模型

### 4.1 变量

| 符号 | 含义 | 来源 |
| :--- | :--- | :--- |
| `EV` | 剩余金额算术均值（或 RMS） | 现有 `OfferCalculator` |
| `min` | 剩余金额最小值（玩家保底） | 现有 |
| `p` | **玩家箱是顶奖的概率** = 剩余顶奖数 ÷ 剩余箱数 | 已有（概率 HUD 同一个值） |
| `confidence` | **银行家信心** = `1 − p`，他赌你拿不到顶奖 | 新增展示 |
| `m_round` | 轮次乘数曲线 | 现有 |
| `rage` | 怒气值 0–100 | 新增 |

### 4.2 报价公式（在现有公式上加两项修正）

```
fear        = max(0, min(0.10 × (p − 0.10), +0.08))        // 你越可能中顶奖，他越怕，越要加价
ragePenalty = 0.06 × rage / 100                            // 你每拒绝一次，他少给一点，最多 −6%
m_eff       = clamp(m_round + fear − ragePenalty, 0, 1)
报价        = clamp(min + (EV − min) × m_eff, min, max)     // 再 floor 到分
```

- `fear` 上限 +8%：让“顶奖还活着”变成他必须多掏钱的理由，这就是“他在赌你拿不到大奖”的可视化。
- `ragePenalty` 上限 −6%：报复存在、可感知，但不至于让玩家觉得被系统坑。
- `m_eff ≤ 1`：报价永远不高于均值（守住 R-6.1.3），也永远不越界（守住 R-6.3）。

### 4.3 数值示例（均值模式）

| 局面（第 6 轮，`m_round = 0.60`） | EV | min | p | fear | rage 0 报价 | rage 60 报价 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 6 箱：$1M + 750k/500k/400k/300k/200k | $525k | $200k | 16.7% | +0.7% | **$397k** | $385k |
| 6 箱：5×$1M + $100k | $850k | $100k | 83.3% | +7.3% | **$605k** | $578k |
| 4 箱：3×$1M + $100k（第 7 轮，0.72） | $775k | $100k | 75% | +6.5% | **$630k** | $606k |
| 2 箱：$1M + $750k（第 9 轮，0.92） | $875k | $750k | 50% | +4% | **$870k** | $866k |
| 2 箱：$1M + $100（第 9 轮） | $500k | $100 | 50% | +4% | **$480k** | $462k |

读法：同样是“顶奖还在”，`p` 越高、`min` 越高，报价越接近均值；反之依然刻薄。**拒绝会让报价小幅下降**，而且玩家看得见原因。

### 4.4 防挫败守卫

1. 怒气压价 ≤ 6%，且永远先算边界钳制，不会把报价压到 `min` 以下。
2. 压价幅度以标签形式**明示**（「怒气压价 −3.6%」），不做暗改。
3. 全等局面直接提前结算（R-5.2.7），不进入报价，怒气不影响该路径。
4. 怒气不改变任何规则（不会减少开箱数、不会提前终局）。
5. 新局怒气归零，局内不衰减（他就这么记仇）。

## 5. 怒气系统

### 5.1 数值

| 项 | 值 | 说明 |
| :--- | :--- | :--- |
| 初始 | 0 | 每局重置 |
| 每次 No Deal | **+15** | 9 轮全拒可到 100（通常第 7 次拒绝满） |
| 上限 | 100 | 满值不溢出 |
| 衰减 | 无 | 局内只增不减 |
| 最高压价 | −6% | 满怒时生效 |

### 5.2 档位与表现

| 怒气 | 档位 | 表情 | 界面 | 音效 | 台词风格 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0–32 | 讥讽 | `smug` | 金色描边 | 正常铃声 | 优雅刻薄 |
| 33–65 | 烦躁 | `annoyed` | 橙色描边 + 怒气条脉冲 | 铃声变短促 | 开始阴阳怪气 |
| 66–99 | 愤怒 | `angry` | 红色描边 + 轻微抖动 | 低音敲桌 | 直接威胁 |
| 100 | 暴怒 | `furious` | 全红 + 掀桌动画（一次性） | 摔电话 + 低频轰鸣 | 破防，暴露底牌 |

### 5.3 反馈时机

- 玩家点 No Deal → 立刻 `+15`，怒气条涨、浮出「+15 怒气」、电话被摔、台词切换。
- 报价出现时，若怒气 ≥ 10，报价下方显示「怒气压价 −X%」。
- 怒气跨越档位时，一次性播放对应表情变化。

## 6. 台词系统

- **事件驱动**：报价出现（按信心高低）、No Deal（按怒气档位）、Deal、玩家开出大额/小额、玩家中顶奖。
- **节奏**：每次事件最多 1 句；同类台词不连续重复（随机池 + 上一次排除）；台词只做情绪，不承载规则信息。
- 示例（正式文案按事件×档位各 3–5 条）：

| 事件 | 示例 |
| :--- | :--- |
| 报价·信心高 | “这个价，够你体面地离开我的赌场了。” |
| 报价·信心低 | “别误会，我只是不想看你哭。拿去吧。” |
| No Deal·讥讽 | “随你。反正钱在我口袋里。” |
| No Deal·愤怒 | “你在挑战我的耐心。” |
| No Deal·暴怒 | “你最好祈祷，下一箱不是那个。” |
| Deal | “聪明。穷人难得聪明一次。” |
| 玩家开出巨额 | “谢谢你的慷慨，我最爱看你心痛的样子。” |
| 玩家开出小额 | “啧……运气站在你那边？” |
| 玩家中顶奖 | “不——！那是我准备买游艇的钱！” |

## 7. 界面方案

放在右侧台面顶部、报价条之上，全程可见：

```
┌──────────────────────────────────────────────────────────┐

│  │ 头像│   怒气 ▓▓▓▓▓▓░░░░ 45   · 拒绝 3 次               │
│  └────┘                                                  │
└──────────────────────────────────────────────────────────┘
```

- 桌面：横向卡片（头像 56px + 信心 + 怒气条 + 拒绝次数 + 气泡）
- 移动：压缩为两行，头像 40px
- 报价出现时，气泡换成报价台词，下方接现有 `OfferPanel`

### 7.2 报价面板增强

在现有报价条里加两个小标签（仅在有修正时出现）：

- `怒气压价 −3.6%`（红）
- `怕你中大奖 +7.3%`（金）

## 8. 与现有规则的衔接

需在需求文档新增 **R-6.4 银行家怒气与恐惧修正**：

- R-6.4.1 怒气 0–100，玩家每次 No Deal 增加固定值，局内不衰减，新局归零。
- R-6.4.2 怒气对乘数施加**有上限的压价**（≤6%），必须明示，且不得突破 R-6.3 边界。
- R-6.4.3 顶奖概率高时可施加**恐惧加价**（≤8%），使报价更接近均值但不得超过均值。
- R-6.4.4 两类修正均不得改变 R-5.2.7 提前结算、R-11.2 与 §7 终局规则。
- §10 配置表新增：`ragePerNoDeal`、`rageMaxPenalty`、`fearGain`、`fearClamp`。
